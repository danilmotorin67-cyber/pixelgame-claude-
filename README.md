# Солёный свет / Saltlight

Пиксельная 2D-игра на Godot. Веха M1 в разработке: доступны островные регионы,
переходы, часы, погода, луна, приливный берег, сон и сохранение после ночи. Полная
спецификация игры — в [docs/full.md](docs/full.md). Игра ещё не готова.
Визуальное направление и первый участок графической переработки описаны в
[docs/ART_DIRECTION.md](docs/ART_DIRECTION.md).

Откройте `project.godot` в Godot 4.4 или новее. Инструкции по сборке ресурсов,
управлению и структуре проекта находятся в [docs/README.md](docs/README.md).

Каждый следующий этап разработки следует сохранять отдельным коммитом и
отправлять в удалённый репозиторий GitHub.

При каждом обновлении GitHub Actions проверяет таблицы данных, импорт проекта
в Godot 4.4.1 и интеграционный сценарий `tests/integration/test_m1.gd`.
